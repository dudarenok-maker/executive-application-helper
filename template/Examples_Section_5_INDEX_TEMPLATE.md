## Housekeeping

- **Target size: 10 KB or less.** If this file outgrows that, the `Pattern (distilled)` column has stopped being distilled. Tighten the entries; do not split the file.
- **Every family carries a `-DEFAULT` row.** It is the answer to "no archetype matched cleanly", and it should be written from the family's core pattern rather than left empty.
- **New archetypes** follow the second-occurrence policy (`Examples_Master.md` Section 5.2): a slim index row plus a `Status: one-shot` row file on first occurrence; promotion to full detail on a second distinct organisation.
- **Keep this index and the row files in sync.** They are two views of one prescription; where they disagree, the row file wins and the index is corrected.
